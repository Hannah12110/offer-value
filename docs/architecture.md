# Phase 1 · 技术方案
版本 0.1.0。交付项目级 .agents/skills/offer-decision；不改 sources 或全局目录。一个 Codex Skill 编排八个逻辑模块；八份研究引用与共同流程/证据/评分规范分离。Codex 使用可用搜索工具研究；Python 标准库负责 JSON 校验、规则、区间评分、薪酬、比较和 Markdown 合成。没有 Python 调模型、爬虫或必需 API。

研究和确定性工具边界：研究者负责真实性、源适配、评分理由；脚本拒绝无效输入、保留未知并执行门槛，不假称验证事实。数据流：自然语言→profile/offer→证据→子指标/阻断状态→校验→计算→十四节报告。默认报告完整但可以有 UNKNOWN；最小输入离线可运行。真实案例单独存 examples，不进入 Skill 默认画像。

MVP 范围：A/B/C 指令流程；结构化单/多评分；年度中国居民综合所得参数化估算或通用税后输入；固定/目标收入与2/3年储蓄；离线入口；报告合成。未来：政策参数更新、FX 情景、证据快照/语义审计、用户回填和概率校准。没有 Web UI、数据库、独立 Agent、自动联系 HR、付费 API 或自动上传。

技术依赖 Python >=3.10，无 pip 依赖。Skill 静态校验器为开发环境工具，不是运行依赖。Codex Desktop/CLI 的发现和自然语言选择属于宿主行为，需要在新会话中验证，不由单元测试证明。
