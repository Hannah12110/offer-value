# Module 4 · Location Intelligence
优先具体办公楼—步行/公交/地铁 30—45 分钟圈；办公点未知时先区间，不套全市均值。核住宅挂牌/实际成交差异、饮食交通消费、社保公积金、税后储蓄、工时通勤、文化公共空间、图书馆/课程、专业社群/展会、同业雇主密度/跳槽、定居政策和长期成本。活动需日期/报名链接；没核实不得称可参加。
三种月预算：保守=控制支出、基准=可持续日常、舒适=较高居住/休闲支出，明确这是支出不是收入乐观程度。逐项租金/水电网/饮食/交通/学习社交/杂费，不重复计通勤/公司福利。押金单列为占用资金，可退押金不全当永久费用。挂牌至少比较房型、位置、管理费、通勤实测，缺口则 ESTIMATE。分别评价日常质量、职业密度、学习资源、人脉、长期生活成本。子指标：生活适配、机会/学习密度、通勤。
