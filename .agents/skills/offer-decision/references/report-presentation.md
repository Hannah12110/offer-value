# 呈现规范：让第一次读的人也能看懂

本文件约束报告的**读者语言、强调方式与图表**。评分、阈值、证据门槛都不因此改变；改的只是把内部规则翻译成读者能直接行动的句子。

## 一、判定语：内部状态只用于脚本，正文一律中文化

脚本输出的 `decision` 与 `evidence_status` 是机器状态，进入正文时必须换成动词句：

| 内部状态 | 正文写法 | 读者要能回答的问题 |
|---|---|---|
| `ACCEPT` | 可以签 | 现在签，理由是什么 |
| `CONDITIONAL_ACCEPT` | 可以有条件地签 | 哪几条书面条件满足后才能签 |
| `NEGOTIATE` | 继续谈薪，暂不签 | 谈哪几项、谈到什么程度 |
| `HOLD` | 先别签，先谈条件 | 缺哪几项证据、谁去要 |
| `DECLINE` | 建议放弃 | 哪条硬约束已确认不可接受 |
| `SUFFICIENT_EVIDENCE` | 证据充分 | 哪些维度已核实 |
| `INSUFFICIENT_EVIDENCE` | 证据不足 | 还缺什么、缺口在谁手上 |

阻断项同样中文化：entity→签约主体、salary→书面薪资、duties→岗位职责、legal_safety→诉讼与处罚、constraints→个人取舍；状态 clear→已确认、unknown→未知、blocked→受阻。规则名写成“评分规则 v1”，`self_reported` 写成“企业自报”。

**不能只做词替换。** 枚举常嵌在判定句里，直接换词会留下病句：

- 原句：“上界未低于 50，不构成 DECLINE；下界未达 65，够不上 CONDITIONAL_ACCEPT。”
- 改写：“58.5 的上限没有低到 50 以下，还不到‘该放弃’的程度；50.7 的下限也没到 65，够不上‘可以有条件地签’。”

阈值一律补一句“到了才算什么”：65 分＝可以有条件地签的门槛，50 分＝低于此即建议放弃，75 分＝可以签（且须已拿到书面 offer）。

## 二、强调：三级，不超过全文 15%

强调过密等于没有强调。三级分工：

1. **红字（结论与红线）**：判定语、退出触发条件、不可逆风险、谈判红线。全文 10—15 处。
2. **浅红底＋红字（关键数字）**：决定判断的数字，如确定部分年薪、税后月均、悬空差额、覆盖率、总分区间。全文 8—12 处。
3. **加粗（次级重点）**：其余关键句，不新增颜色。

规矩：
- 顶部结论块用浅红底承载“建议＋三句理由＋解锁条件”，正文其余位置不再重复结论。
- 表格里只对**状态类单元格**整格标红（如覆盖率 33%、未解阻断项），不对整行铺色；需要标“你在这里”的行可以整行浅红底，但同一张表最多一行。
- 颜色用于表达语义并在全篇一致：红＝不可逆或必须行动；靛青／灰＝中性事实与结构。

## 三、图表：分数必须能被看见

评分结论至少配三张图，各回答一个独立问题，不得拼成大而全的仪表盘：

| 图 | 回答的问题 | 必需要素 |
|---|---|---|
| 加权贡献叠加 | 总分由哪几个维度垒起来、距门槛差多少 | 每维“分数×权重”从下界顺序累加；50／65／75 三条门槛线；合计区间标注；缺口差值写在图下 |
| 覆盖度 | 哪些维度的分其实没有证据支撑 | 八维覆盖条；100%／67%／33% 三色；说明“合格证据子项数／3”；标明加权口径的覆盖率与简单子项计数的差别 |
| 敏感性 | 换一组权重，结论会不会翻转 | role／economics ±5 的落点；50 与 65 两条参考线；结论“未翻转”或“翻转”写在图下 |

制作要求：
- 每张图前一段提出它要回答的问题并交代口径与单位；图后一段写“读图”结论，说明它如何影响下一判断。禁止只放图不给解释。
- 图内必须有图例颜色说明、单位、时间／统计期与来源脚注；关键数值直接标注，不藏在悬浮提示里。
- 表与图分工：表负责查数（区间、权重、覆盖、子项理由），图负责看位置与形状；同一组数据不得在图和表中重复呈现同一信息。
- 载体为 HTML5 图块（`html5-block`），宽度自适应 820px、不横向滚动、高度自动；不得用 Python 导出 PNG 冒充数据图表；连续两个视觉块之间必须有段落过渡。
- 每个图块只服务一个判断，标题写成结论而不是“评分总览”。

## 四、交付前自检

1. 对全文做一次正则扫描，确认无 `ACCEPT`、`DECLINE`、`HOLD`、`CONDITIONAL_ACCEPT`、`INSUFFICIENT_EVIDENCE`、`unknown`、`clear`、`blocked`、`self_reported` 残留——表格状态格与图表图例最容易漏。
2. 数一遍：红字处数 ≤15% 篇幅阈值、浅红底 8—12 处、三张评分图齐全且都在对应章节。
3. 回读线上文档确认样式真的落库（颜色会被归一化为 rgb 值，不能按命名色字符串计数判断失败），并核对一级标题数、图数、首尾段完整。
4. 每张图都能用一句话说出“它帮读者判断什么”；说不出来的删掉。
